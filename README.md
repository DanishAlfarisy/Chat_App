# Chat_App
A simple chat application built as a learning project to explore backend development with Node.js, Express.js, MySQL, and React.

## 🚀 About The Project

This project was created to practice building a full-stack application from scratch, starting from a REST API backend and connecting it to a React frontend.

The backend is built with **Node.js and Express.js**, while **MySQL** is used to store users and chat messages. The frontend is built separately using **React** and communicates with the backend through HTTP requests.

## 🛠️ Tech-Stack

- **Node.js** — JavaScript runtime for the backend
- **Express.js** — Web framework for building the REST API
- **MySQL** — Relational database
- **mysql2** — MySQL driver for Node.js
- **React** — Frontend UI
- **Vite** — React development and build tool
- **JavaScript** — Main programming language
